# 明示的型キャスト

Tsuzuri は異なる数値型間での暗黙の型変換を行いません。ビット幅の異なる整数間の拡大変換や縮小変換、整数と浮動小数点数の相互変換、ならびに 2 進浮動小数点と 10 進浮動小数点の変換は、すべて `as` 演算子（または専用の変換関数）を用いて明示的に記述します。すべてのキャスト規則はハードウェア固有の未定義動作を排除しており、ネイティブ環境と WebAssembly 環境で同一の結果を返します。

## 要点

- **`Numeric` 型間の明示変換**: `式 as 型` は両辺が `Numeric` 型クラスを満たす固定幅整数・2進浮動小数点・10進浮動小数点（および `Numeric<'a>` 制約付きの型変数）の間で使用できます。
- **整数間はビット拡張・切り詰め**: 拡大変換は符号付きなら符号拡張、符号なしならゼロ拡張を行い、縮小変換は上位ビットを切り捨てて下位ビットを保持します（飽和はしません）。
- **浮動小数点→整数は切り捨て・飽和・`NaN → 0`**: 小数部はゼロ方向へ切り捨てられ、表現範囲外の値や `±inf` は目的の整数型の最小値・最大値へ飽和し、`NaN` は常に **`0`** へ変換されます。
- **2進浮動小数点と10進浮動小数点の直接変換**: `f16`〜`f128` と `d32`〜`d128` の間も `as` で直接相互変換でき、中間型を経由する二重丸めを起こしません。
- **非数値型の変換は専用 API を使用**: `char`・`utf8char`・`BigInt`・`bool`・`string` には `as` を適用できず（`E1005`）、`Char.to_u16`、`BigInt.to_i64`、`to_string`、`Parse.parse` を使用します。

## `as` 演算子の構文と優先順位

```text
式 as 変換先の型
```

`as` は左結合の後置風二項演算子であり、べき乗演算子 `**` よりも高い結合優先順位を持ちます（関数適用やフィールドアクセス・添字よりは低く結合します）。

- `x as f32 as f64` は `(x as f32) as f64` として左から順に評価されます。
- `2i8 ** 8 as i16` は `2i8 ** (8 as i16)` と解析され、左辺 `i8` と右辺 `i16` の型不一致で `E1003` になります。べき乗の底を先に拡大する場合は `(2i8 as i16) ** 8` と括弧で囲みます。
- 関数適用は `as` より強く結合するため、`Math.sqrt x as f32` は `(Math.sqrt x) as f32` と解釈されます。

## 数値間のキャスト規則マトリクス

変換元と変換先の組み合わせごとの可否および正確な丸め・境界動作は以下のとおりです。

| 変換元 ＼ 変換先 | 符号付き整数 (`i8`〜`i128`) | 符号なし整数 (`i8u`〜`i128u`) | 2進浮動小数点 (`f16`〜`f128`) | 10進浮動小数点 (`d32`〜`d128`) | 非 `Numeric` 型 (`char` / `BigInt` / `bool` 等) |
| --- | --- | --- | --- | --- | --- |
| **符号付き整数** | 拡大: 符号拡張<br/>縮小: 下位ビット切り詰め | 拡大: 符号拡張後に再解釈<br/>同幅: ビット保持<br/>縮小: 下位ビット切り詰め | IEEE 754 最近接偶数丸め（範囲外は `±inf`） | IEEE 754 十進最近接偶数丸め | 不可（`E1005`） |
| **符号なし整数** | 拡大: ゼロ拡張<br/>同幅: ビット保持<br/>縮小: 下位ビット切り詰め | 拡大: ゼロ拡張<br/>縮小: 下位ビット切り詰め | IEEE 754 最近接偶数丸め（範囲外は `+inf`） | IEEE 754 十進最近接偶数丸め | 不可（`E1005`） |
| **2進浮動小数点** | ゼロ方向切り捨て・範囲外は `MIN`/`MAX` 飽和・`NaN` は `0` | ゼロ方向切り捨て・負数と `NaN` は `0`・上限超過は `MAX` 飽和 | 拡大: 厳密保持<br/>縮小: 1 回の最近接偶数丸め | 中間型を介さず目的の十進精度へ直接丸め | 不可（`E1005`） |
| **10進浮動小数点** | ゼロ方向切り捨て・範囲外は `MIN`/`MAX` 飽和・`NaN` は `0` | ゼロ方向切り捨て・負数と `NaN` は `0`・上限超過は `MAX` 飽和 | 中間型を介さず目的の2進精度へ直接丸め | 拡大: 厳密保持<br/>縮小: 十進最近接偶数丸め | 不可（`E1005`） |
| **非 `Numeric` 型** | 不可（`E1005`） | 不可（`E1005`） | 不可（`E1005`） | 不可（`E1005`） | 不可（`E1005`） |

## 整数間の変換（拡大変換・縮小切り詰め・符号再解釈）

整数同士の `as` キャストは 2 の補数ビット表現に対する決定論的なビット操作を行います。

1. **符号付き整数の拡大変換（符号拡張 / Sign Extension）**: 元の最上位ビット（符号ビット）を上位の全ビットへ複製し、負の数も数値としての値を保ちます（例: `-1i8 as i16u` は `0xFF` を 16 bit へ符号拡張した `0xFFFF` すなわち `65535i16u` になります）。
2. **符号なし整数の拡大変換（ゼロ拡張 / Zero Extension）**: 上位ビットをすべて `0` で埋め、非負の値をそのまま保ちます（例: `255i8u as i16` は `255i16`）。
3. **縮小変換（下位ビット切り詰め / Truncation）**: 変換先のビット幅に収まる下位 $N$ ビットのみを取り出します。飽和演算ではないため、`255i64 as i8` は `127i8` ではなく `-1i8`（`0xFF`）、`256i64 as i8u` は `0i8u` になります。
4. **同ビット幅の符号変換**: ビット列を一切変更せず符号解釈のみを切り替えます（`-1i32 as i32u` は `4294967295i32u`）。

```tsuzuri run=-1:65535:255:-1:0
let sign_ext_signed = -1i8 as i64
let sign_ext_unsigned = -1i8 as i16u
let zero_ext = 255i8u as i16
let narrow_signed = 255i64 as i8
let narrow_wrap = 256i64 as i8u

$"{sign_ext_signed}:{sign_ext_unsigned as i64}:{zero_ext as i64}:{narrow_signed as i64}:{narrow_wrap as i64}"
```

範囲外を検出して安全に失敗させたい場合は、`as` で切り詰める前に値の範囲を比較するか、`BigInt` 経由の変換関数を利用します。

## 整数から浮動小数点への変換

整数から 2 進浮動小数点（`f16`〜`f128`）または 10 進浮動小数点（`d32`〜`d128`）へのキャストは、IEEE 754 の**最近接偶数丸め（roundTiesToEven）**で行われます。

- `f64` の仮数は 53 ビットであるため、絶対値が $2^{53}$（$= 9{,}007{,}199{,}254{,}740{,}992$）以下の整数は誤差なく厳密に表現されます。それを超える `i64` / `i64u` / `i128` の整数は最も近い表現可能値（ちょうど中間の場合は仮数最下位ビットが偶数になる側）へ丸められます。
- 変換先の最大有限値を超える巨大な整数（例: `100000i32 as f16`）は `+inf`（負なら `-inf`）へ丸められます。
- `d128` は有効桁数 34 桁を持つため、`i64` および `i64u`（最大 20 桁）のすべての整数値を一切の丸め誤差なく厳密に表現できます。

```tsuzuri run=true:true
let tie_odd = 9007199254740993i64 as f64
let tie_even = 9007199254740992i64 as f64
let exact_d128 = (9007199254740993i64 as d128 as i64) == 9007199254740993i64
$"{tie_odd == tie_even}:{exact_d128}"
```

## 浮動小数点から整数への変換（切り捨て・飽和・`NaN` 規則）

2 進浮動小数点（`f16`〜`f128`）および 10 進浮動小数点（`d32`〜`d128`）から任意の整数型（`i8`〜`i128`、`i8u`〜`i128u`）への `as` キャストは、以下の 3 規則によって全入力域で完全に定義されています。

1. **ゼロ方向への切り捨て（Truncation toward zero）**: 小数部は常にゼロへ近づく方向に切り捨てられます（`3.99 as i64` は `3`、`-3.99 as i64` は `-3`）。四捨五入や床関数が必要な場合は、キャスト前に [`Math.round_even`](../stdlib/numeric/math.md) や `Math.floor` を適用します。
2. **飽和変換（Saturating cast）**: 切り捨て後の整数値が変換先型の表現範囲を超える場合、および正負の無限大（`+inf` / `-inf`）は、変換先型の最大値または最小値へクランプされます。負の浮動小数点数を符号なし整数型（`i8u`〜`i128u`）へキャストした場合は `0` に飽和します（`-1.0 as i8u` は `0i8u` であり、`255i8u` にはなりません）。
3. **`NaN` は必ず `0`**: 非数 `NaN`（正負・quiet/signaling・2進/10進を問わず）を整数へキャストした結果は、すべての整数型で必ず **`0`** になります。

```tsuzuri run=3:-3:127:-128:0:255:0:0
let pos_trunc = 3.99 as i64
let neg_trunc = -3.99 as i64
let sat_max = (1.0 / 0.0) as i8
let sat_min = (-1.0 / 0.0) as i8
let neg_to_unsigned = -42.5 as i8u
let pos_to_unsigned = 1.0e20 as i8u
let bin_nan_zero = (0.0 / 0.0) as i64
let dec_nan_zero = (0.0d64 / 0.0d64) as i64

$"{pos_trunc}:{neg_trunc}:{sat_max as i64}:{sat_min as i64}:{neg_to_unsigned as i64}:{pos_to_unsigned as i64}:{bin_nan_zero}:{dec_nan_zero}"
```

## 浮動小数点同士・2進と10進の相互変換

### 同系統の浮動小数点間キャスト

- **2進浮動小数点同士（`f16` ↔ `f32` ↔ `f64` ↔ `f128`）**: 広い型への変換は値を厳密に保ち、狭い型への変換は 1 回の最近接偶数丸めを行います。`f64 as f16` も `f32` を経由せず直接 `f16` へ 1 回だけ丸められ、表現範囲外は `±inf` になります。`NaN` は符号ビットを保持したまま変換先の正規化 quiet NaN へ変換されます。
- **10進浮動小数点同士（`d32` ↔ `d64` ↔ `d128`）**: 広い型への変換は厳密であり、狭い型への変換は IEEE 754 十進最近接偶数丸めに従います。

### 2進浮動小数点と10進浮動小数点の相互変換

2 進浮動小数点型（`f16`・`f32`・`f64`・`f128`）と 10 進浮動小数点型（`d32`・`d64`・`d128`）のすべての組み合わせで **`as` による双方向変換が可能**です。変換時は `f64` などの中間形式を介さず、変換元の正確な数学的値から変換先の形式へ直接最近接偶数丸めを行います。

```tsuzuri run=true:0.25
let dec: d64 = 0.1d64
let approx_bin: f64 = dec as f64
let exact_quarter: d64 = 0.25f32 as d64
$"{approx_bin > 0.0999999999 && approx_bin < 0.1000000001}:{exact_quarter}"
```

なお、`0.1d64` のように 2 進で有限小数にならない値を `f64` に変換したあと再び `d64` に戻すと、`f64` への丸め誤差が反映された十進値になる点に注意してください。

## ジェネリック型変数へのキャストと変換関数

### 型変数へのキャスト（`expr as 'a`）

ジェネリック関数の内部で具体的な数値を型パラメータ `'a` へ変換する場合は、`'a` に `Numeric<'a>`（またはその部分集合である `Integer<'a>` / `SignedInteger<'a>` / `UnsignedInteger<'a>` / `Float<'a>`）制約が付与されていれば `expr as 'a` を記述できます。

```tsuzuri run=42:42.5
def add_ten :: Numeric<'a> => 'a -> 'a
    @'a : Add = \x -> x + (10 as 'a)

$"{add_ten 32}:{add_ten 32.5}"
```

### 組み込み変換関数 `to_float` と `to_int`

高階関数やパイプライン演算子 `|>` で頻用される `i64` と `f64` の相互変換には、第一級関数として渡せる組み込み関数が提供されています。意味論は `x as f64` および `x as i64` と同一です。

```text
to_float :: i64 -> f64
to_int   :: f64 -> i64
```

```tsuzuri run=45
let scores = [10.9, 20.1, 15.8]
scores |> Array.map (\x -> to_int x) |> Array.sum
```

## `as` を使わない変換（文字・多倍長整数・文字列・真偽値）

`Numeric` ではない型との変換は、失敗可能性やエンコーディング契約を型で明示する専用関数で行います。

| 変換対象 | 使用する関数・構文 | 型シグネチャと失敗時の挙動 |
| --- | --- | --- |
| `char` ↔ `i16u` | `Char.to_u16` / `Char.of_u16` | `char -> i16u` / `i16u -> char`（全 65,536 値で全単射・可逆） |
| `utf8char` → `i32u` | `Utf8Char.to_u32` | `utf8char -> i32u`（常に成功） |
| `i32u` → `utf8char` | `Utf8Char.of_u32` | `i32u -> Maybe<utf8char>`（サロゲート `0xD800..=0xDFFF` や `> 0x10FFFF` は `None`） |
| `i64` ↔ `BigInt` | `BigInt.from_i64` / `BigInt.to_i64` | `i64 -> BigInt` / `ref BigInt -> Maybe<i64>`（`i64` 範囲外は `None`） |
| 任意の表示可能型 → `string` | `to_string` / `Display.display` / `$"..."` | `Display<'a> => 'a -> string`（浮動小数点は最短往復表記） |
| `ref string` → 数値・`bool` | `Parse.parse` | `Parse<'a> => ref string -> Maybe<'a>`（不正形式・範囲外は `None`） |
| `bool` ↔ 整数 | `if b then 1 else 0` / `n != 0` | 条件分岐と比較式で明示 |

```tsuzuri run=65:true:true:42
let code = Char.to_u16 'A'
let invalid_surrogate = Maybe.is_none (ref (Utf8Char.of_u32 0xD800i32u))
let big_ok = Maybe.default_value 0 (BigInt.to_i64 (ref 42I)) == 42
let parsed: Maybe<i64> = Parse.parse "42"

$"{code as i64}:{invalid_surrogate}:{big_ok}:{Maybe.default_value 0 parsed}"
```
